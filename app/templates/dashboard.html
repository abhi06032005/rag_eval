Data Integrity & Research Transparency Statement

In strict compliance with systems research ethics and EDISS standards, this repository maintains total separation between genuine measurements and synthetic artifacts:

  • Live Document Acquisition: All 500 arXiv documents and 500 English Wikipedia documents were acquired via authenticated live API requests with canonical content hashes and timestamped snapshot IDs.
  • GovInfo Disclosures: As detailed in data_integrity_report.md, GovInfo data utilizes synthetic legislative templates modeled on real federal circulars to avoid restricted bulk API quotas.
  • Evaluation Set Integrity: The 100 development questions and 50 test questions were derived via deterministic lexical span extraction. The test set is transparently documented as synthetic/unverified — zero claims of manual human annotations are fabricated.
  • Index Reproducibility: All Qdrant vector spaces, scalar quantisation thresholds, and HNSW graph degrees are deterministically reproducible using scripts/run_benchmarks.py.

Scientific Integrity & Methodological Separation Notice

In strict compliance with empirical systems research standards, RAGScaleBench categorizes experimental evaluations into four mutually exclusive tiers:

  • Tier A (Exploratory Synthetic Smoke Tests): Synthetic fixture evaluations (50 queries with title leakage, in-memory local collection). Documented as exploratory smoke tests, not publication evidence.
  • Tier B (Authentic External Benchmark): BEIR SciFact (5,183 abstracts, 300 claims, 339 qrels). Provides reproducible, zero-leakage evaluation against human-annotated scientific ground truth.
  • Tier C (Vector Database Engine Audit): Dedicated standalone Qdrant Rust server v1.19.2. Measures active HNSW index creation, INT8/1-bit quantization rescoring, actual on-disk directory sizes, and process RSS RAM.
  • Tier D (HTTP Load Testing): Concurrency sweeps against the live FastAPI service measuring serialization, network IPC, and worker queuing saturation up to 20 concurrent clients.

Policy: In-memory vector operations (e.g. NumPy matrix cosine product at 0.45 ms) are strictly labeled as microbenchmarks and are never conflated with network service performance.

Formal Non-Inferiority Testing Procedure

Replaces unsupported "equivalent" claims with formal non-inferiority testing.

Hypothesis: H_0: μ_Hybrid - μ_Adaptive ≥ δ vs H_1: μ_Hybrid - μ_Adaptive < δ
Pre-specified Margin: δ = 0.025 nDCG (Carterette 2007 standard practical limit)
Observed Difference: -0.0010 nDCG
Upper 95% Confidence Limit (UCL_95): 0.0082
Non-Inferiority p-value: p < 0.0001
✓ Statistically Non-Inferior: UCL_95 (0.0082) < δ (0.025)

Because the upper bound of the 95% confidence interval for hybrid advantage over adaptive retrieval is 0.0082, any true quality deficit is guaranteed to be under 0.0082 with 95% confidence—substantially below the 0.025 threshold of practical relevance.
